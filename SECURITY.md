# Security policy

If you believe you've found a security vulnerability in a Sireto repository, please report it privately. Do not open a public issue, pull request or discussion.

**How to report:** use **Report a vulnerability** on the repository's **Security** tab. If that option isn't available, open an issue that asks for a private contact and contains no details of the vulnerability.

Please include what is affected, how to reproduce it, and the impact you expect. We acknowledge reports within 3 working days and keep you informed until the issue is resolved.

Please give us reasonable time to fix the issue before disclosing it, and don't access or modify data that isn't yours while testing.
