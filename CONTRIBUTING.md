# Contributing

Thanks for contributing to a Sireto repository.

- **Open or find an issue first** and describe the change you intend to make.
- **Work on a short-lived branch** named `feat/…`, `fix/…`, `chore/…` or `docs/…`, and open a pull request. Protected branches accept changes only through pull requests.
- **Write commit messages as [Conventional Commits](https://www.conventionalcommits.org/)**, for example `fix(api): reject empty names`.
- **Keep pull requests small and single-purpose**, fill in the template, and link the issue with `Fixes #123` (or `Refs #123` if it doesn't close it).
- **Every pull request is reviewed** before it merges, and CI must pass.
- **Never commit secrets** (tokens, passwords, keys, `.env` files) or personal data, including in tests.

Security issues: please don't open a public issue. See [SECURITY.md](SECURITY.md).
